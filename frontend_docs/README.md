# BoiMix Frontend Docs

This folder contains the frontend planning, product specification, and feature-audit documents for BoiMix.

## Documents

- `boimix_complete_product_architecture_master_document.md`
  - Main product and frontend architecture/source document.
- `frontend_feature_logic_audit.md`
  - Full frontend feature and logic audit based on the current codebase.
- `implementation_plan.md`
  - Frontend implementation planning notes.
- `plan.md`
  - Frontend phase memory and progress notes.
- `test prompt.md`
  - Prompt/instruction document used during the frontend planning workflow.

## Frontend Scope

- Next.js App Router frontend
- Dashboard-first UI surface
- Mock/local-state-heavy flows that will later connect to backend APIs
- Route, feature, and UI logic inventory for backend integration planning
